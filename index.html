浏览器推送开启失败？请按以下步骤排查

1. 检查系统权限：
Windows：设置 → 隐私和安全性 → 通知，开启浏览器通知；再检查「专注助手/勿扰模式」是否关闭。
手机：系统设置 → 应用 → 浏览器 → 通知，允许通知。

2. 检查浏览器权限：
点击地址栏左侧的锁形 / 齿轮 图标 → 找到「通知」→ 设为「允许」，然后刷新页面重试。

3. 确认访问方式：
浏览器推送需要 HTTPS 网址（本站已支持）。若从本地文件打开（file:// 开头）则无法使用。

4. 浏览器兼容性：
推荐使用 Chrome 或 Edge 电脑版/手机版。部分小众浏览器或无痕模式不支持推送。

5. iOS 用户：
需将网页「添加到主屏幕」后从主屏幕图标打开，才能使用推送。

仍然失败？可改用下方「微信推送」功能，微信收提醒更省心。
